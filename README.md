# Первый Android-проект

Это мой первый проект на Android с использованием Jetpack Compose. Проект создан в Android Studio и настроен для сборки через Gradle.

## 🎯 Цель проекта

Простейшее приложение, которое демонстрирует:
- Базовую структуру Android‑проекта.
- Работу с Jetpack Compose (UI на Kotlin).
- Разбиение на слои: Clean Architecture.
- Внедрение зависимостей: Hilt.
- Работу с сетью: Retrofit.

> 💡 Это учебный проект: код написан для понимания основ, а не для продакшена.

##  Для работы с сетью

| Метод | Адрес | Назначение |
| :---: | :---: | :---: |
| GET | http://<BASE_URL>/catalog | Получить весь каталог приложений |
| GET | http://<BASE_URL>/catalog/{id} | Получить приложение по ID |
