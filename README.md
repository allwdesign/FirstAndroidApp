# Первый Android-проект

Это мой первый проект на Android с использованием Jetpack Compose. Проект создан в Android Studio и настроен для сборки через Gradle.

## 🎯 Ветка создана для практической работы
1. Явные Intent
   - Приложение с двумя Activity.
   - На экран первой Activity добавлено поле для ввода текста.
   - На экране первой Activity добавлена кнопка "Открыть вторую Activity".
   - При нажатии передача строки из поля для ввода.
   - Во второй Activity отображается эта строка на экране.
   
2. Неявные Intent
   - Добавлена кнопка "Позвонить другу" на экран первого Activity.
   - При нажатии используется неявный Intent для открытия приложения звонков
   (ACTION_DIAL) с номером телефона из поля EditText.

3. Системные Intent
   - Добавлена кнопка "Поделиться текстом" на экран первой Activity.
   - При нажатии отправляется Intent (ACTION_SEND) с текстом из EditText.
   - Появляется системное окно «Поделиться через…».
   
4. Добавлена валидация данных. Если они не валидны, пользователю выводится сообщение об ошибке.
5. Все ДЗ сделано в отдельном pull request, который НЕ будет влит в итоговый проект.
